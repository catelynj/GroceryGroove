# Grocery Groove
_Game & Simulation Programming Capstone_
### Overview
Grocery Groove is a mobile rhythm game for iOS devices. It features one level with 2 difficulties and an original song. Players take on the role of Clerk Kent who is the non-chalant final boss of grocery store workers. 
Their boss, Mr. Kellen P. Pole, is a maniacal store manager that has _very_ high standards. Scan items to the beat of the song and avoid making mistakes or face your manager's wrath.

### Technologies/Credits
This is created in Unity2D game engine with a majority of functionalities using original C# scripts. There is a simplistic SQLite database for storing highscores and usernames. The music featured in the main level is original, created in BandLab.
Character art was drawn by me and the store background in the menus is an altered image I created. Grocery items are pictures of real items with a filter over them placed by me.
